# Personal Portfolio Website

A modern, responsive, and performant personal portfolio website built to showcase project work, technical skills, and professional experience.

Live Demo: [atharvagarg.live](https://atharvagarg.live)

---

## Features

- **Responsive Design:** Optimized across desktop, tablet, and mobile displays.
- **Project Showcase:** Highlights featured projects with live links, source code, and key features.
- **Skills & Experience:** Clear layout of technical competencies, tools, and background.
- **Contact Integration:** Easy access for recruiters, collaborators, and visitors to reach out.
- **Performance Optimized:** Fast loading times, accessible layout, and SEO-friendly structure.

---

## Tech Stack

- **Frontend:** HTML5, CSS3 , JavaScript 
- **Deployment:** Vercel
- **Domain & DNS:** Custom domain via `atharvagarg.live`
